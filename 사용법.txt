AltTabFlow 1.1.5 · Windows x64

1. ZIP 파일의 압축을 모두 풀고 AltTabFlow 폴더를 보관할 위치에 둡니다.
2. AltTabFlow.exe를 실행합니다. 별도 설치나 .NET 설치가 필요하지 않습니다.
3. 이후 알림 영역에 상주합니다. 중복 실행하면 기존 창을 엽니다.

[빠른 전환]
Alt+Tab 한 번: 직전 프로그램을 선택합니다. 누른 키를 모두 놓으면 전환합니다.
다시 Alt+Tab 한 번: 이전 프로그램으로 돌아갑니다.
마우스로 실제 프로그램 창이나 그 프로그램의 팝업을 클릭한 뒤에도 그 창을 기준으로 전환합니다.
아주 짧게 눌렀다 놓은 입력은 선택 화면과 FX를 만들기 전에 바로 전환할 수 있습니다.
Alt를 누른 채 Tab 반복: 표시된 목록의 다음 항목을 선택합니다.
방향키로 이동한 뒤에도 Alt·Tab·방향키 등 누른 키를 모두 놓으면 선택한 창으로 전환하고 닫힙니다.
Alt를 먼저 놓고 방향키를 잡고 있으면 계속 이동하며, 마지막 방향키를 놓을 때 전환합니다.
Chrome처럼 여러 창이 묶인 앱은 하이라이트에 표시된 대표 창으로 전환합니다.
Alt+Shift+Tab: 역방향 선택.

[묶음 탐색 / 고정 상세 선택]
Alt+Tab으로 연 상태의 방향키·묶음 탐색은 키를 모두 놓으면 확정됩니다.
Enter: 여러 창이 묶인 앱 펼치기 / 개별 창으로 전환.
Backspace: 이전 앱 목록으로 돌아가기. 검색 중이면 글자 지우기.
Esc: 선택 취소하고 원래 창으로 돌아가기.
Ctrl+Alt+Space: 상세 선택 화면 열기 / 닫기.
Ctrl+Alt+Tab: 상세 선택 화면, 반복하면 다음 항목.
Ctrl+Alt+Space나 Ctrl+Alt+Tab으로 연 고정 상세 화면은 키를 놓아도 유지됩니다.
검색·설정·항목 메뉴를 명시적으로 연 경우에도 기존처럼 화면을 유지합니다.
Ctrl+1 / 2 / 3: 목록 / 카드 / 아이콘.
F2: 설정.

[이름순 정렬]
설정 → 상단 정렬에서 먼저 볼 프로그램을 체크합니다.
상단 등록 앱끼리 A~Z → 가나다순, 나머지도 그 아래에서 같은 순서입니다.
등록한 순서는 영향을 주지 않습니다. 같은 앱의 개별 창은 최근 사용 순입니다.
실행 중이 아닌 앱은 프로세스 이름(chrome.exe 등)을 입력해 등록합니다.
Ctrl+P 또는 항목 우클릭으로도 상단 등록/해제가 가능합니다.

[색상과 포커스 강조]
설정 → 색상 · 효과에서 7개 프리셋을 선택하고 저장합니다.
민트 다크 / 오션 블루 / 바이올렛 / 로즈 / 앰버 / 노르딕 / 클라우드 라이트
대상 창 앞으로 미리 보여주기: 선택 중인 실제 창을 전환 화면 바로 아래로 올립니다.
위에 떠 있는 다른 프로그램이 있어도 대상 창을 앞에 표시하고, 취소하면 원래 상태로 복원합니다.
아우라: 테마 강조색의 빛이 창 모서리를 빠르게 순환합니다.
Alt+Tab 포커스 강조: 주변은 30% 어둡게, 대상 창은 선명하게, 아우라는 더 강하게.
기본으로 켜져 있으며 각각 설정에서 해제할 수 있습니다.
선택 취소나 목록 변경 시 임시로 바꾼 창의 앞뒤 순서를 복원합니다.
최소화된 창은 미리 올리지 않으며 실제로 전환할 때 복원합니다.

[자동 실행 / 숨기기 / 종료]
Windows 로그인 자동 실행은 기본으로 켜져 있습니다.
설정 → 기본 동작 → Windows 시작 시 자동 실행을 해제하면 등록을 제거합니다.
해제한 선택은 다음 실행과 업데이트에서도 유지됩니다.
자동 실행을 사용할 때는 실행 파일의 폴더를 유지해 주세요.
다른 폴더로 옮겼다면 새 위치에서 한 번 실행하면 시작 경로가 갱신됩니다.
앱 숨기기: 항목 우클릭 → 이 앱을 목록에서 숨기기.
숨김 해제: 설정 → 숨길 앱에서 이름 제거 후 저장.
일시 중지: Ctrl+Alt+F12.
종료: 알림 영역 아이콘 우클릭 → 완전히 종료 (기본 Alt+Tab 복원).

설정은 %LOCALAPPDATA%\AltTabFlow\settings.json에 보관됩니다.
ZIP에는 개인 설정이나 창 제목 기록이 포함되지 않습니다.
번들 런타임의 라이선스는 licenses 폴더를 참고하세요.

[메이플스토리 등 관리자 권한 게임에서만 Windows Alt+Tab이 나올 때]
Game-compat-mode.cmd를 실행하고 Windows 권한 확인에서 예를 선택합니다.
기존 AltTabFlow를 정상 종료한 뒤 관리자 권한으로 다시 실행합니다.
권한 확인을 취소하면 기존 일반 모드로 다시 켭니다. 강제 종료하지 않습니다.
이미 관리자 권한으로 실행 중이면 중복 실행하지 않습니다.
이는 실행 권한을 맞추는 호환 방법입니다. 게임 보안 프로그램이나 전체화면의
모든 제약을 해결한다고 보장하지 않으며, 실제 게임 화면에서 전환을 확인합니다.
로그인 자동 실행은 일반 권한입니다. 재부팅 후 게임에 필요하면 이 실행 도구를
다시 사용합니다. 자동 실행 해제 설정과 Windows 보안 설정은 바꾸지 않습니다.
일반 모드로 돌아가려면 트레이에서 완전히 종료하고 AltTabFlow.exe를 실행합니다.

[개발 프로젝트의 버전 관리]
package.ps1 실행 시 releases 폴더에 버전·날짜별 ZIP을 추가합니다.
AltTabFlow-latest-win-x64.zip은 최신 검증 완료본입니다.
latest.json과 .sha256 파일로 버전·크기·무결성을 확인할 수 있습니다.
