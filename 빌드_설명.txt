AltTabFlow 1.1.5 | Windows x64 소스와 자동 빌드 키트

[현재 상태]
- 1.1.1 전체 소스에 1.1.2 정식 변경 패치를 적용한 26개 파일입니다.
- ContextMenuStrip 우클릭 메뉴 종료 오류를 수정하고 메뉴 회귀 검사를 추가했습니다.
- 이 저장소에는 소스와 자동 빌드 스크립트가 있으며 Windows 실행 파일(EXE)은 포함되지 않습니다.
- GitHub 이관 환경에서는 Windows 컴파일 및 117+10+7+18 (10개 중복)개 런타임 검사를 실행하지 않았습니다.
- Windows CI 후보는 실제 게임/다중 모니터 창 제어 검증을 의미하지 않습니다.

[Windows 배포 빌드]
1. 저장소를 내려받아 압축을 해제합니다.
2. Windows-Build.cmd를 실행합니다.
3. .NET 8 SDK가 없으면 설치 여부를 묻습니다.
4. package.ps1이 self-contained EXE와 ZIP을 만들고 142개 고유 자동 검사 실행을 시도합니다.
5. 세 검사가 모두 통과해야 releases\AltTabFlow-latest-win-x64.zip이 생성됩니다.

[주의]
- Windows 잠금 화면의 LockApp은 창 미리 표시 테스트를 가릴 수 있습니다. 잠금 해제 후 재검사하세요.
- 메이플스토리가 관리자 권한으로 실행되면 Game-compat-mode.cmd를 이용할 수 있습니다.
- 개인 설정과 앱 창 제목이 포함된 진단 로그를 GitHub에 등록하지 마세요.

[1.1.5]
- 일반 Alt+Tab 방향키 탐색 후 모든 키가 해제된 시점에 현재 선택 창으로 전환합니다.
- 명시적 고정 상세 화면은 기존대로 유지합니다.
- 테스트 검증에 사용한 현재 작업 계정의 CI 결과와 명세 작성자의 142개 검증 이력을 구별합니다.
