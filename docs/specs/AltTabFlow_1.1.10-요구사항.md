# AltTabFlow 1.1.10 사용자 요청 / 승인 기준

2026-11-10 후속 요청. 기반 main: v1.1.9.

## 요구 1 — 재부팅 뒤 관리자 권한 자동 실행

- 기존 1.1.9는 게임 호환 관리자 모드 버튼을 눌러도 Windows Run 기반 자동 시작에서는 일반 권한으로 복귀.
- **최초 1회** "Windows 시작 시 자동 실행" + "로그인 시 관리자 권한으로 자동 시작"을 선택해 UAC 승인하면 이후 로그인 때 추가 UAC 없이 현재 로그인 사용자의 **Interactive token + Highest run level** 예약 작업으로 시작.
- SYSTEM/서비스 데스크톱 사용하지 않음. 기존 HKCU Run 등록과 중복 실행 금지.
- 권한 높은 예약 작업은 사용자 쓰기 Downloads/AppData에 직접 연결 금지. Program Files 보호 설치 경로로 안전하게 배포.
- UAC 취소·등록 실패 시 이전 설정과 실행본 유지, 해제 시 예약 작업 제거/일반 자동 시작 복원.

## 요구 2 — 업데이트 창 표시 및 먹통 회귀

- 증상: '업데이트 확인' 버튼 클릭 시 정체 모를 창이 순간 나타났다 사라진 뒤 조작이 불가능하고 ESC를 눌러야 복귀.
- 인과관계는 실사용 화면/로그 없이는 확정할 수 없음. 단기 중첩 토큰 팝업·TopMost/owner 체인을 제거하고 항상 보이는 독립 Form에 인증 입력, 진행률/상태, 취소/오류를 표시.
- 토큰은 Windows Credential Manager에서만 읽기/저장. 취소 시 EXE 교체·앱 종료 금지. 네트워크 취소 지원.
- 업데이트 성공 시 별도 교체 도우미가 실행본 종료 후 바꾸고 재시작. 프로그램이 종료될 때까지 전용 업데이트 창이 종료를 방해하지 않음.

## 요구 3 — 마우스 휠 일반 모드 전환

- 기존 SwitcherForm.MouseWheel의 'persistent=true' 때문에 일반 Alt+Tab 도중 휠 탐색 후 마지막 키 해제 Commit이 무시됨.
- 휠은 항목 선택만 변경, 고정/일반 플래그 변경 금지.
- 일반 Alt+Tab은 휠로 마지막 선택된 창을 *관련 키 전부 놓는 순간* 한 번 전환.
- Ctrl+Alt+Tab 고정 상세는 휠로 탐색해도 마지막 해제에 자동 Commit 금지.

## 검증 범위

- Windows CI: 입력 206 + UI 80(휠 5·업데이트 창 4 추가) + 업데이트 11 + 예약 시작 11 = **308개** 예상.
- 실제 사용자 PC: Task Scheduler 등록 및 로그아웃/재로그인, UAC 승인/취소, 관리자 메이플스토리·P4, 실제 비공개 GitHub 토큰 다운로드/버전 교체·재시작.
